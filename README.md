# أندية المعلمين والعاملين — محرر الكتب الرسمية للأندية

موقع ثابت (HTML/CSS/JavaScript) يعمل داخل المتصفح، جاهز للنشر على GitHub Pages.

## المستندات
كتاب للوزارة · كتاب داخلي · كتاب شكر · تعميم هيئة عامة.
- ترويسة: «نادي + اسم النادي».
- **التوقيع:** رئيس الهيئة الإدارية ومدير النادي في كل النماذج، ولكل منهما خيار إظهار/إخفاء (الاسم والتوقيع والختم).
- جدول، مرفقات (صور/PDF/ماسح ضوئي)، وخيارات تنسيق كاملة.

## الخطوط
Simplified Arabic (افتراضي)، Traditional Arabic، Sakkal Majalla، Arabic Typesetting، Andalus، Segoe UI، Tahoma، Arial، Times New Roman، Calibri، وخطوط مضمّنة تعمل دون اتصال: Cairo، Tajawal، Almarai، IBM Plex Sans Arabic، Amiri، Noto Naskh Arabic.
الخطوط المضمّنة تظهر في المعاينة وPDF والطباعة؛ وفي ملف Word يُكتب اسم الخط فقط، فإن لم يكن مثبتًا على الجهاز يستبدله Word بخط آخر.

## التصدير والمشاركة
- Word / PDF / طباعة / بريد / واتساب / أيقونة Google Drive: يُسمّى الملف تلقائيًا بعنوان **الموضوع** المكتوب في الكتاب.
- Drive: تنزّل الملف ثم تفتح صفحة Drive لرفعه («جديد ← رفع ملف»).

## الواجهة والحفظ
معاينة ظاهرة دائمًا، وضع ليلي، حفظ دائم في المتصفح (IndexedDB)، ونسخ احتياطي من إعدادات الموقع.

## التشغيل والنشر
```bash
cd teachers-clubs-editor
python3 -m http.server 8000   # ثم http://localhost:8000
```
GitHub Pages: ارفع محتويات المجلد إلى جذر المستودع، ثم Settings ← Pages ← `main` و`/ (root)`.

## كتاب الشكر
- «الجهة الموجه إليها الكتاب» أصبحت مربع كتابة حرًّا (كل سطر في سطر مستقل).
- خيار «تكرار الكتاب»: اكتب جهة في كل سطر فيُنشأ نسخة من الكتاب في صفحة جديدة لكل جهة (في المعاينة وWord وPDF والطباعة).

## تبويبات جديدة وتحسينات
- **قرار تكليف**: نموذج الكتاب الداخلي مع صندوق «اللجنة المالية» أسفل رئيس الهيئة، ومنتقي تاريخ يُدرج في النص (الرمز [تاريخ التكليف]) مع إمكانية الكتابة اليدوية.
- **مطالبة مالية**: حسب النموذج المرفق، وجميع الحقول قابلة للتعديل.
- لوحة ضبط مواضع الختم والتوقيع والأسماء (أزرار أعلى/أسفل/يمين/يسار لكل عنصر)، وتحريك صندوق الجهة في كتاب الشكر.
- مؤشر تحميل أثناء تجهيز الملفات، ومنع الضغط المتكرر، وذاكرة مؤقتة للملفات، وتنزيل بأسماء المواضيع.

## سحب الأختام والتواقيع والأسماء
اسحب الاسم أو الختم أو التوقيع مباشرة على المعاينة (ماوس أو لمس)؛ الصفة تتحرك مع الاسم. انقر لتحديد عنصر وحرّكه بالأسهم (Shift = خمسة أضعاف). الوضع الافتراضي: الختم والتوقيع أسفل الاسم، مع خيار فوق الاسم أو متراكب معه.

## الشعارات والمرفقات وتحرير النص
- شعار الوزارة وشعار الأندية ثابتان (لا رفع ولا إزالة ولا إخفاء)، والتحكم بحجمهما فقط.
- المرفقات: صور من الجهاز، PDF، «الماسح الضوئي» (يختار ملف الصورة/PDF الناتج عن برنامج المسح لأن المتصفح لا يشغّل تعريف الماسح مباشرة)، و«تصوير بالكاميرا» (معاينة مباشرة وعدة لقطات، مع بديل التقاط الهاتف).
- شريط تحرير النص: زر «كشيدة» (مدّ الحرف) و«إزالة الكشيدة»، و«صورة» لإدراج صورة داخل النص (انقر عليها للتكبير/التصغير/الحذف)، وتظهر في Word وPDF والطباعة.
